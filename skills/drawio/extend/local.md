# 本仓库适配

本文件补充官方 Skill 的宿主与交付约定；发生冲突时，用户指令优先，其次本文件，再按官方原文执行。

- 只在用户指定 draw.io 时接管图表任务；独立交互 HTML 沿用 `archify`，普通图表不额外初始化自驱编码工作区或后端任务。
- 随包官方 Skill 和 XML / Mermaid 参考已完整提供，不要求安装另一个插件市场、插件、IDE 扩展或 MCP。官方示例中的 `/drawio:drawio` 是其插件命令，当前宿主直接使用本 Skill 即可。
- 任务实际用到 Mermaid 转换、自动布局或 PNG/SVG/PDF 导出时，再顺势检测目标机器的 draw.io Desktop CLI、版本和所需参数；仅生成原生 XML 不做安装前置检查。按官方对应系统的查找顺序检测，不能只因 PATH 中没有命令就判定未安装；找到后直接用其绝对路径，无需用户改 PATH。
- 已有能力直接继续。确实未安装或版本不支持时，明确提醒受影响的步骤，并按当前系统给出官方安装/升级入口、最短操作步骤及完成后的续做步骤；同一缺口不反复提醒。可继续的图表工作先完成，保留带明确布局、可逐节点编辑的 `.drawio`；环境补齐后从未完成的转换或导出步骤接着做。不让用户补转换脚本，不声称已导出，不自行安装软件或改环境。
- 正式产物保存在目标项目约定目录；中间文件、截图和 `.url` 放该项目 `tmp/`。始终保留 `.drawio` 源文件及用户已有修改，覆盖前先读取原文件；导出成功也不执行官方示例中删除源文件的步骤。多页图保留全部页面，导出时按用户要求选择页面。
- 官方修复脚本只在确认存在对应 XML 错误时使用；对用户已有文件优先精确修复，避免整份重写。检查 XML 转义、唯一 cell ID、父子关系、连线端点和 geometry，防止生成空图或悬空连线。
- 文件或网页的打开与操作遵循用户和宿主已有授权；不要直接执行官方示例中的 `open`、`start` 或 `xdg-open`。需要 URL 时才生成包含图内容的分享链接；仅有本地交付要求时不把内容发送到在线服务。
- 交付前由 Agent 完成当前环境能做的验证：源文件结构检查；有已授权编辑器或 CLI 时，实际打开或导出，检查节点、中文、连线、容器和页面是否完整、文字是否遮挡。重新打开源文件确认节点仍可编辑，修改任务确认原有页面和内容保留。结构检查、导出成功、视觉与编辑验收分别按实际结果报告；缺少运行条件时明确未验证部分，不把任务交回用户手填参数或修文件。
